# 🥋 Thai Go Academy (โปรแกรมสอนและฝึกเล่นหมากล้อมแบบโต้ตอบ)

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **🎓 บทเรียนพื้นฐานแบบโต้ตอบ (Interactive Lessons 6 หมวด 12 บทเรียน):**
   - กฎกติกา ลมหายใจ การจับกิน กฎห้ามฆ่าตัวตาย กฎโค
   - การสร้างสองห้องรอด ตาจริง/ตาปลอม สภาวะเซคิ
   - เทคนิคการจับกิน (ขั้นบันได ตาข่าย งับกลับ)
   - หลักการเปิดเกม (ฟุเซกิ: มุม -> ข้าง -> กลาง)
   - มือนำและมือตาม (เซนเต้ & โกเต้) และการปิดเกม (โยเสะ)

2. **🧩 คลังโจทย์ฝึกหัด & แก้ทาง (Graduated Puzzles 24 ข้อ):**
   - เรียงลำดับจากง่ายไปยาก (ระดับเริ่มต้น -> ปานกลาง -> ท้าทาย)
   - ตรวจจับความถูกต้องตามกฎหมากล้อมสากล 100%

3. **🤖 กระดานซ้อมมือ & ผู้ช่วยโค้ช AI (Interactive AI Coach):**
   - รองรับกระดานขนาด **9×9, 13×13, และ 19×19**
   - **บอกเจตนาของทุกตาเดิน:** `[⚔️ โจมตี]`, `[🛡️ ป้องกัน]`, `[💎 เสริมรูปร่าง]`, `[🏗️ ขยายโครงสร้าง]`, `[🏁 ปิดเกม]`, `[✨ เทซูจิ]`
   - **วิเคราะห์สถานะแต่ละโซน (Territory & Safety Status):** แจ้งเตือนโซนที่ชนะปลอดภัย 100% เพื่อไม่ให้เดินซ้ำในบ้านตัวเอง และโซนที่กำลังปะทะ
   - เตือนทันทีเมื่อเผลอวางหมากอุดตาจริงของตัวเอง (Real Eye)

4. **🔊 เสียงวางหมากกระทบกระดานไม้ Kaya เสมือนจริง:**
   - สังเคราะห์เสียงด้วย Web Audio API แบบ Acoustic Physics หลายชั้น (Snap, Knock, Deep Resonance)
   - ทำงานออฟไลน์ 100% โดยไม่ต้องโหลดไฟล์ภายนอก

5. **📱 โหมดขยายเต็มกระดานสำหรับสมาร์ทโฟน (Zen Fullscreen Mode):**
   - ซ่อนเมนูที่ไม่จำเป็นเพื่อให้เห็นทั้งกระดานเต็มๆ ทั้ง 9, 13, 19 เส้น
   - ระบบสัมผัสป้องกันหน้าจอเลื่อน พร้อม Mobile Drawer ลอยตัว

## 🚀 วิธีเปิดใช้งานออนไลน์บน Vercel (Deployment Guide)

### วิธีที่ 1: Deploy ผ่าน GitHub (แนะนำที่สุด - อัปเดตอัตโนมัติ)
1. อัปโหลดโปรเจกต์นี้ขึ้น GitHub Repository ของคุณ
2. เข้าสู่ระบบที่ [vercel.com](https://vercel.com)
3. กดปุ่ม **"Add New..."** -> **"Project"**
4. เลือก Repository นี้ แล้วกด **"Deploy"** (Vercel จะตรวจจับเป็น Static Site ให้อัตโนมัติทันที)
5. รอประมาณ 30 วินาที จะได้ URL เว็บไซต์พร้อมใช้งานทันที (เช่น `https://thai-go-academy.vercel.app`)

### วิธีที่ 2: Deploy ผ่าน Vercel CLI (บนเครื่องคอมพิวเตอร์)
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์:
```bash
cmd /c npx vercel
```
หรือหากติดตั้ง Vercel CLI แล้ว:
```bash
vercel
```
ทำตามขั้นตอนบนหน้าจอเพื่อล็อกอินและยืนยันการ Deploy
